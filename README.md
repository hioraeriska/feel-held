Entry for [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) on make.fun.

`main.ts` (Node 22) writes one short text to `/output/entry.txt`: a reader
who has answered a thousand knocks finds one door already open, a lamp low,
and a chair with their name on it, while the world keeps its noise outside.
It asks nothing of the reader: no answer, no verdict, no next step.

The text is 210 Unicode code points, well inside the 1–280 limit, and the
program is deterministic: every run writes the same bytes.
